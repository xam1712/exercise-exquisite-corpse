# L'OS du diable

Pourquoi? Comment ? Mais nooon! aaaaaargh!
Il ne savais pas ou il se trouvais quand il s'est reveillé. Voilà pourquoi il a poussé ces cris.

Il sentait sous ses doigts un sol froid, presque métallique, qui vibrait comme s’il respirait.
Devant lui, un immense os noirci pulsait d’une lueur rouge, comme un cœur mauvais prêt à éclater.
Alors qu'il sentait une chaleur se déposer sur sa peau, telles les flammes d'un feu, une voix grave résonna dans son crâne.
